# 개인정보 안내 초안

상태: **MVP 검수용 초안 — 공개 처리방침 아님**

한강갈까는 친구들과 공평한 한강공원 약속 장소를 정하기 위해 필요한 최소 정보만 사용합니다.

## 수집·이용하는 정보

- 약속 날짜와 도착 완료 시각
- 참여자가 직접 정한 별칭
- 선택한 출발역 또는 공개 장소의 참조값
- 공원별 예상 이동시간과 추천 결과

계정, 이메일, 전화번호를 요구하지 않습니다. MVP에서는 현재 위치와 정확한 주소를 받거나 저장하지 않습니다.

## 이용 목적

- 참여자별 대중교통 이동시간 계산
- 공평한 추천 공원과 대안 생성
- 약속 변경 시 추천 갱신
- 참여자가 자신의 입력을 수정하거나 삭제하도록 권한 확인

## 다른 사람에게 보이는 정보

- 방장도 참여자의 출발역·장소를 볼 수 없습니다.
- 초대 링크만 연 사람은 참여자의 별칭과 이동시간을 볼 수 없습니다.
- 제출을 완료한 참여자와 방장은 참여자별 별칭과 예상 이동시간을 볼 수 있습니다.
- 추천 공원, 대안, 만남 지점과 추천 근거는 약속 참여자에게 표시됩니다.

## 외부 서비스 전송

대중교통 경로 계산을 위해 출발·도착 좌표를 지도 경로 공급자에게 전송할 수 있습니다. 별칭, 약속 링크와 권한 토큰은 함께 보내지 않습니다. 서울시 상황 데이터 조회에는 참여자의 출발 위치를 보내지 않습니다.

실제 공급자명, 국외 이전 여부, 위탁·제3자 제공 관계와 법적 고지 문구는 배포 전 계약·약관과 운영 구조를 기준으로 확정합니다.

## 보관과 삭제

- 완성되지 않은 약속: 생성 7일 후 자동 삭제
- 일정이 있는 약속: 약속 시각 24시간 후 자동 삭제
- 방장 수동 삭제: 서비스 데이터에서 즉시 접근 불가 및 삭제 처리
- 복구용 백업: 최대 30일 안에 순환 삭제

삭제 시 약속, 별칭, 출발 장소 참조, 이동시간, 추천 기록과 링크 권한을 함께 삭제합니다.

## 사용자의 선택

- 참여자는 자신의 출발 장소를 수정하거나 참여 정보를 삭제할 수 있습니다.
- 방장은 약속 전체를 삭제할 수 있습니다.
- 로그인 없는 MVP에서는 브라우저 쿠키를 지우거나 기기를 바꾸면 수정·삭제 권한을 복구할 수 없습니다.

## 공개 전 추가할 정보

- 운영자명과 연락처
- 개인정보 보호 문의·열람·삭제 요청 절차
- 실제 호스팅·데이터베이스·로그·백업 공급자
- 지도 공급자와 데이터 전송에 관한 정확한 법적 고지
- 정책 시행일과 변경 이력
