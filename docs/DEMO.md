# 클릭 가능한 fake 핵심 여정

## 목적

실데이터와 최종 디자인을 붙이기 전에 다음 제품 계약이 하나의 웹 여정으로 연결되는지 검증한다.

1. 방장이 약속을 만든다.
2. 설치와 로그인 없이 공유 링크로 친구가 참여한다.
3. 친구 2명이 별칭과 출발역을 제출한다.
4. 같은 계산 결과에서 추천 1곳, 대안 1곳, 만남 지점과 비교 근거를 표시한다.
5. 방장이 참여 현황과 같은 추천 결과를 확인한다.

## 실행과 검수

Node.js 22.12 이상에서 의존성을 설치한 뒤 두 터미널을 사용한다.

```bash
npm install
npm run dev:api
```

```bash
npm run dev:web
```

브라우저에서 `http://127.0.0.1:5173`을 열고 다음을 확인한다.

1. 약속 시간을 정하고 **피크닉 약속 만들기**를 누른다.
2. 방장 화면의 **친구 화면 열기**를 새 탭에서 연다.
3. 예를 들어 `민지 · 홍대입구역`을 제출한다.
4. 같은 화면에서 **다른 친구 입력도 테스트하기** 또는 다시 표시된 입력 폼을 사용해 `준호 · 강남역`을 제출한다.
5. 추천과 대안, 정확한 만남 지점, 참여자별 이동시간, 평균·최장·차이가 표시되는지 확인한다.
6. 방장 탭에서 **새로고침**을 눌러 참여자 2명과 동일한 결과가 표시되는지 확인한다.

고정 fixture 기준으로 위 두 출발역을 입력하면 추천은 **여의도한강공원**, 대안은 **이촌한강공원**이다.

## 현재 보호 경계

- 초대·방장 토큰은 256비트 난수이며 서버 메모리에는 SHA-256 해시만 저장한다.
- 권한 토큰은 `HttpOnly`, `SameSite=Strict` 쿠키로 전달한다.
- 방장 결과에는 친구 별칭과 이동시간만 표시하고 출발역 식별자는 반환하지 않는다.
- 클라이언트가 추천을 재계산하지 않고 서버의 구조화된 결과만 표현한다.

## 의도적으로 남긴 제한

- 서버를 재시작하면 약속이 사라지는 메모리 저장소다.
- 6개 출발역과 11개 공원의 고정 이동시간만 사용한다.
- 혼잡·날씨·행사·통제와 지도 연결은 아직 없다.
- 추천 개정과 방장 승인, 링크 만료·자동 삭제는 아직 동작하지 않는다.
- 같은 브라우저에서 두 친구를 연속 제출하는 기능은 검수 편의를 위한 임시 동작이다.
- 현재 화면은 기능 검수용이며 최종 디자인 시스템을 적용하지 않았다.
