# 한강공원 피크닉 특징 카탈로그

검증일: 2026-08-12

## 목적과 상태

추천 결과가 이동시간과 혼잡도만 나열하지 않고, 후보를 선택했을 때 무엇을 할 수 있는지 설명하기 위한 정적 카탈로그다. 시설 존재와 공원 특징은 서울시 미래한강본부 공식 공원 소개에서 확인했다. 운영시간·계절 개장·예약 가능 여부는 변할 수 있으므로 동적 운영 상태로 간주하지 않으며 결과에 재확인 안내를 함께 표시한다.

요약과 분류 태그는 공식 사실을 피크닉 의사결정에 맞게 짧게 편집한 값이다. 생성형 AI가 추천 시점에 문구나 시설을 추가하지 않는다. 실행 데이터는 [`park-experience-catalog.ts`](../backend/src/infrastructure/catalog/park-experience-catalog.ts)에 있으며, 누락된 공원은 임의의 기본 문구로 대체하지 않고 오류로 처리한다.

## 대안 구성 규칙

1. **오늘의 추천:** 균형 정책의 전체 1순위.
2. **이동 균형 대안:** 같은 정책의 차순위 후보.
3. **다른 즐길거리 대안:** 상위 7개 후보 안에서 앞선 두 후보에 없는 대표 경험 태그를 가진 첫 후보. 없으면 안정적인 정렬의 3순위.

대표 경험 태그는 1순위 점수에 보너스로 넣지 않는다. 현재 MVP에서 즐길거리는 사용자가 후보 차이를 이해하고 대안을 선택하는 근거이며, 실제 피크닉 사례 검증 전까지 “즐길거리 수가 많을수록 무조건 좋은 공원”으로 계산하지 않는다.
