# 개인정보·공유 링크 위협 모델

상태: **사용자 승인 완료 — MVP 기준 정책**

작성일: 2026-08-12

이 문서는 MVP 구현 전에 수집 범위, 권한, 삭제와 공유 링크 위험을 제한한다. 법률 자문을 대신하지 않으며 공개 배포 전 실제 사업자 정보·외부 공급자 관계·개인정보 처리방침을 다시 검토한다.

## 근거와 설계 원칙

- 개인정보 보호법 제16조는 목적에 필요한 최소한의 개인정보를 수집하도록 하고, 최소 수집이라는 입증책임을 개인정보처리자에게 둔다: <https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335669>
- 개인정보 보호법 제21조는 보유기간이 지나거나 목적을 달성해 불필요해진 개인정보를 지체 없이 복구·재생할 수 없도록 파기하도록 한다: <https://www.law.go.kr/LSW/lsLinkCommonInfo.do?ancYnChk=&chrClsCd=010202&lsJoLnkSeq=1020398651>
- OWASP는 자체 세션 토큰에 CSPRNG 기반 최소 128비트를 권고하고, URL 토큰이 로그·방문기록·리퍼러 등에 노출될 수 있다고 경고한다: <https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html>
- `Referrer-Policy: no-referrer`는 외부 이동 시 공유 URL이 `Referer` 헤더로 전달되는 것을 막는다: <https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Referrer-Policy>

따라서 계정·이메일·전화번호를 MVP에서 수집하지 않고, 정확한 주소·현재 좌표를 보관하지 않으며, 링크 토큰은 최소 권한·짧은 수명·로그 금지를 적용한다.

사용자 승인일: 2026-08-12

## 확정 데이터 범위

| 데이터 | 수집 목적 | 활성 약속 중 저장 | 다른 참여자에게 표시 |
|---|---|---|---|
| 약속 날짜·도착 완료 시각 | 추천·갱신 예약 | 예 | 예 |
| 참여자 별칭 | 참여 상태·시간 비교 | 예 | 제출 완료 후 별칭과 이동시간만 |
| 공개 장소 참조 | 경로 재계산 | 조건부 예 | 아니요 |
| 주소 원문·현재 좌표 | MVP에서 수집하지 않음 | 아니요 | 아니요 |
| 참여자별 이동시간 | 공평성 설명 | 예 | 제출 완료 참여자와 방장 |
| 추천 개정본 | 변경 비교·방장 승인 | 예 | 공원·근거만 |
| 초대·방장·참가자 토큰 | 권한 판정 | 원문이 아닌 해시만 | 아니요 |
| 이메일·전화번호·계정 | 필요 없음 | 아니요 | 아니요 |

`공개 장소 참조`는 역 또는 공개 POI의 내부/공급자 식별자와 최소 표시명이다. 카카오 결과 식별자의 지속 저장이 약관상 허용되는지 확정 전에는 임의 POI 보관을 구현하지 않는다. 허용되지 않으면 자체 공공 역 카탈로그로 MVP 입력을 제한한다.

## 확정 수명주기

```text
약속 생성
  ├─ 미완성 초안: 생성 7일 후 자동 삭제
  └─ 일정 확정: 약속 진행
       ├─ 방장 수동 삭제: 활성 DB에서 즉시 삭제
       └─ 정상 종료: 약속 시각 24시간 후 자동 삭제
                    └─ 백업은 복구 전용으로 최대 30일 내 순환 삭제
```

- 삭제 대상은 약속, 참여자, 장소 참조, 이동시간, 추천 개정본과 모든 권한 토큰이다.
- 수동 삭제 후 링크는 즉시 `deleted` 상태가 되고 데이터를 다시 만들거나 다른 약속으로 연결하지 않는다.
- 백업에서 복원하면 삭제 목록을 먼저 재적용해 삭제된 약속이 되살아나지 않게 한다.
- 분석 지표는 약속·토큰·장소·별칭과 연결되지 않은 집계값만 남긴다. 원본 이벤트 보관은 초기 MVP에서 하지 않는다.

## 권한표

| 행동 | 초대 링크 보유자 | 제출 완료 참가자 | 방장 |
|---|:---:|:---:|:---:|
| 날짜·목적·참여 인원 보기 | O | O | O |
| 새 참여 정보 제출 | O | - | - |
| 자기 출발지 확인·수정·삭제 | X | O | X |
| 다른 사람 출발지 보기 | X | X | X |
| 제출 후 별칭·이동시간 비교 | X | O | O |
| 날짜·시간 수정 | X | X | O |
| 참가자 제거 | X | X | O |
| 추천 확정·변경 승인 | X | X | O |
| 약속 전체 삭제 | X | X | O |

방장도 출발지를 보지 못한다. 잘못된 위치는 참가자가 직접 수정하며, 방장은 별칭·제출 상태·이동시간만 확인한다.

## 링크와 토큰 구조

- 초대, 방장, 참가자 권한을 서로 다른 256비트 무작위 토큰으로 발급하고 서버에는 해시만 저장한다.
- 공유되는 초대 토큰은 참여와 공개 약속 정보 조회만 허용한다.
- 방장 토큰은 약속 생성 직후 `HttpOnly`, `Secure`, `SameSite=Strict` 쿠키로 저장하고 공유 URL에 넣지 않는다.
- 참가자 토큰도 제출 직후 해당 브라우저의 보안 쿠키로 저장한다.
- 방장이 참여자로도 출발지를 제출하면 방장 권한과 별도로 자신의 참가자 토큰을 함께 가진다.
- MVP에는 이메일·전화번호·계정이 없으므로 방장·참가자 토큰의 기기 간 복구를 제공하지 않는다. 쿠키를 잃으면 방장은 관리 권한을 복구할 수 없다.
- 초대 URL을 사용하는 페이지는 `Referrer-Policy: no-referrer`, `Cache-Control: no-store`를 적용하고 제3자 분석 스크립트를 넣지 않는다.
- 서버 로그는 실제 URL 대신 `/meetings/:meetingId` 같은 라우트 템플릿만 기록하며 토큰·쿼리·별칭·장소·좌표를 기록하지 않는다.
- 토큰 검증 시 일정한 실패 응답, 요청 속도 제한과 만료·폐기 검사를 적용한다.

## 위협과 통제

| 위협 | 영향 | 제안 통제 | 검증 |
|---|---|---|---|
| 초대 링크 추측 | 약속 정보 열람·스팸 참여 | 256비트 토큰, 속도 제한, 만료 | 토큰 형식·권한 테스트 |
| 초대 링크 유출 | 링크 보유자의 참여 | 초대 권한 최소화, 폐기/재발급 | 초대로 관리 기능 접근 실패 |
| URL이 로그·리퍼러로 유출 | 제3자가 링크 재사용 | 원본 URL 로그 금지, `no-referrer`, 제3자 스크립트 금지 | 로그 허용목록 테스트·헤더 E2E |
| 초대 링크로 방장 행위 | 장소 임의 변경·삭제 | 방장 토큰 완전 분리 | 권한 행렬 테스트 |
| 참가자가 타인 위치 열람·수정 | 위치 노출·추천 조작 | 참가자별 토큰, 객체 소유권 검사 | IDOR 시나리오 |
| 방장이 출발지 원문 열람 | 친구 위치 과다 노출 | API 응답 계약에서 원문 제외 | 계약 테스트 |
| 토큰 탈취 | 권한 도용 | 보안 쿠키, CSP, XSS 방어, 짧은 수명 | 보안 헤더·XSS 검사 |
| 삭제 후 데이터 잔존 | 목적 종료 뒤 위치 보관 | 즉시 활성 삭제, 자동 만료, 백업 30일 | 삭제·복원 테스트 |
| 분석·오류 로그 유출 | 위치·토큰 장기 보관 | 필드 허용목록, URL·body 금지 | 로그 정제 테스트 |
| 외부 경로 공급자 전송 | 출발 위치가 공급자에 전달 | 별칭·약속 토큰 없이 좌표만 전송, 공급자 고지 | 요청 계약 검사 |
| 대량 약속 생성·참여 | 비용·서비스 방해 | IP/토큰별 속도 제한, 참여 상한 | 429·재시도 테스트 |

## 보안 로그 허용 필드

허용: 무작위 요청 ID, 라우트 템플릿, HTTP 메서드·상태, 처리시간, 공급자명, 정규화 오류 코드.

금지: 실제 URL·쿼리, 요청/응답 body, 모든 권한 토큰, 별칭, 출발지 표시명·식별자, 주소, 위도·경도, 지도 공급자 원본 응답, 공유 링크.

## 승인된 세 가지

1. **입력 범위:** MVP에서 카카오에 등록된 공개 장소 키워드 검색만 제공하고 현재 위치 권한·주소 직접 입력은 제외한다. 검색 결과의 주소는 선택을 구분하는 동안만 표시하며 약속에는 장소 ID와 이름만 남긴다.
2. **보관:** 미완성 초안 7일, 확정 약속은 약속 시각 24시간 후 삭제하며 백업은 최대 30일 보관한다.
3. **복구와 공개 범위:** 로그인 없이 방장·참가자 권한 복구는 제공하지 않고, 제출 완료 참가자끼리는 별칭과 이동시간만 본다.
